# Mechanic Calendar Lite

Mechanic Calendar Lite to lekka aplikacja do zarządzania rezerwacjami warsztatu i grafikami pracowników.

## Darmowe użytkowanie
Aplikacja jest dostępna do korzystania za darmo.

## Instalacja
1. Skopiuj pliki projektu na serwer WWW z obsługą PHP i MySQL/MariaDB.
2. Utwórz bazę danych oraz użytkownika MySQL dla aplikacji.
3. Otwórz w przeglądarce `install/index.php` i postępuj zgodnie z instrukcjami instalatora.
4. Po zakończeniu instalacji zaloguj się do panelu.
